# Structure-aware conditional-MM and PLL

Computes conditional masked-marginal components and full-sequence PLL for MIF, MIFST, ProSST-1024, and SaProt-35M-AF2 on the prepared Tsuboyama double-mutant assays, followed by the shared thermodynamic/additive fit.

Inputs and versions:
- ProteinGym code: `OATML-Markslab/ProteinGym`, commit `144fe22b07dfaeec2b366f2346203a9838a55b4c`
- ProteinGym v1.3 reference and AF2 structures: Zenodo record `15293562`
- MIF/MIFST: Zenodo record `6573779`; sequence-model code commit `af695772c4a1c056d930c95ec7e6428aa042f5cd`
- MIFST CARP-640M: Zenodo record `6564798`
- ProSST-1024: `AI4Protein/ProSST-1024`, revision `8c630087ff3cfee63e666105de85c0bab0760766`; official precomputed ProteinGym 1024-state structure tokens
- SaProt-35M-AF2: `westlake-repl/SaProt_35M_AF2`, revision `316cd4017d29f4657b959365f24b57f1ee278912`; 3Di tokens generated by Foldseek with ProteinGym's pLDDT masking settings

Checkpoints, structures, generated 3Di tokens, and results remain under `/data/users` and are not committed.

```bash
scripts/reanalysis/structure_plm_mm_pll/prepare.py --pilot  # omit flag for all assays
cd results/reanalysis/tsuboyama/structure_plm_mm_pll/condor/pilot
condor_submit_dag -maxjobs 4 analysis.dag
```
